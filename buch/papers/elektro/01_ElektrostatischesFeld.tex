\section{Elektrostatisches Feld\label{elektro:section:EFeld}}
\kopfrechts{Elektrostatisches Feld}

Ein elektrisches Feld beschreibt die räumliche Verteilung der Kraftwirkung, die eine elektrische Ladung auf andere Ladungen ausüben kann.
Das elektrostatische Feld ordnet jedem Punkt im Raum eine Richtung und eine Feldstärke zu. Platziert man an einem beliebigen Punkt eine gedachte positive Probeladung, so erfährt sie eine elektrische Kraft. Die Richtung dieser Kraft entspricht der Richtung des elektrostatischen Feldes an diesem Ort, während ihre Größe die Feldstärke des Feldes beschreibt.
