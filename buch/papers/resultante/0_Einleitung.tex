\section{Einleitung\label{resultante:section:einleitung}}
\kopfrechts{Einleitung}

Für die lösung von Integralen, greifen Ingenieur:innen sowie Sturdierende oft auf Computeralgebrasysteme (CAS) zurück.
Damit CAS fähigen Rechner Integrale lösen können werden effiziente Algorithmen benötigt.
Dabei müssen die Linearfaktoren/Nullstellen des Nenners bestimmte werden.

In Abschnitt \ref{buch:ratint:section:rothsteintrager} wird der Satz Rothstein-Trager beschrieben, die für die bestimmung der Nullstellen die Resultante nutzt.
In verschiedenen Textbücheren wird die Resultant als
\begin{equation}
    \operatorname{Res}(f,g)=\det(\operatorname{Syl}(f,g))
    \label{resultante:equation:definition}
\end{equation}
definiert. Dabei ist die Resultante eine determinante einer Matrix. Aber was ist \(\operatorname{Syl}\)?

In diesem Kapitel wird die Resultante beschrieben und was für nützliche Eigenschafte diese besitzt.
